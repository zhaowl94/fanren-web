# 凡人修仙传 · AI 说书人（Web 版）

> 一款由 **DeepSeek 大模型实时生成剧情**的互动小说游戏，覆盖《凡人修仙传》人界篇全部剧情。
> 玩家扮演韩立：**谨慎、藏拙、步步为营**——选择决定生死，失败亦可转世重来。

## ✨ 功能

- 🎭 **AI 说书人**：DeepSeek v4 Flash 实时叙述，古风白话文风，人界篇剧情自由展开
- 🗺️ **里程碑轨道**：人界篇 14 个里程碑（七玄门入门→墨大夫→黄枫谷→血色禁地→乱星海→结丹→天南→大晋→元婴→化神→飞升），引擎强制按顺序推进——AI 只能自由发挥过程，大节拍不偏离原著
- 🎮 **混合交互**：AI 生成建议选项（可点击）+ 自由输入任意行动（"去坊市摆摊卖假丹"也行）
- 🎚️ **回复模式**：输入区可切换**简略**（80~150 字，只交代关键事件）/ **详细**（300~600 字，细节丰满），每轮回答前自由切换，剧情推进不受影响
- 📊 **修行状态面板**：境界 / 寿元 / 灵石 / 地点 / 剧情进度（里程碑 x/14）/ 随身物品
- 🏷️ **输入/回复区分**：你的行动（✦ 你，右侧气泡）与说书人叙述（📖 说书人，卡片式分块）一目了然
- 💾 **多存档**：localStorage 自动存档 + 导出/导入 JSON，一人可开多条修仙线（谨慎流/作死流）
- ☯️ **道陨与转世**：韩立死亡 → "道陨"界面 → 转世重来（带着上一世死因的模糊记忆），或重开新档
- 📜 **古风排版**：宣纸质感、书法标题、对话/内心/旁白样式区分、打字机动画
- 🧠 **长线记忆**：历史对话自动浓缩为"大事记"摘要，人界篇玩到底不失忆

## 🎯 里程碑机制（主线锚定）

纯自由生成最大的风险是剧情漂移（韩立提前结丹、人物乱入）。本作用**里程碑轨道**解决：

1. **14 个里程碑**按原著顺序钉死大节拍（见 `milestones.js`）
2. AI 每轮必须上报 `beat`（当前剧情阶段词，如：杂役/收徒/起疑/识破/禁地/结丹…）
3. 引擎根据 beat 映射判断推进，**只允许 +1 顺序推进**：跳跃钳制、回退忽略、未识破阴谋就离开七玄门这类大偏离直接拦截
4. AI 漏报时，引擎自动做一次轻量"阶段判定"调用兜底
5. 推进时界面显示"⚡ 里程碑达成"横幅，面板"剧情"进度同步更新

## 🚀 快速开始

```bash
cd fanren-web
npm install
# 编辑 .env 填入你的 DeepSeek API Key
npm start
# 浏览器打开 http://localhost:3000
```

## ⚙️ 配置 API（供应商/密钥/模型）

**页面配置（推荐）**：启动后打开游戏页面 → 点右上角「**密钥**」按钮 → 填写三项：

- **Base URL**：默认 `https://api.deepseek.com`（支持任意 OpenAI 兼容接口，如硅基流动、通义等，换供应商改这里即可）
- **API Key**：必填
- **模型名称**：默认 `deepseek-v4-flash`（ds v4 flash）

「保存并验证」会先连通性测试，通过后写入 `.env` 并**即时生效，无需重启服务器**。

**或编辑 .env**：

```
DEEPSEEK_BASE_URL=https://api.deepseek.com   # 供应商接口地址
DEEPSEEK_API_KEY=sk-你的密钥                  # 必填，在 platform.deepseek.com 申请
MODEL=deepseek-v4-flash                      # 模型名
PORT=3000                                    # 服务端口
```

> ⚠️ `.env` 已被 .gitignore 排除，密钥不会进入版本库。浏览器端永远接触不到密钥，所有 API 调用经由后端代理。

## 🏗️ 架构

```
浏览器（public/）                    Node.js 后端（server.js）
┌──────────────────────┐   POST /api/chat    ┌─────────────────────────┐
│ index.html           │ ──────────────────► │ 组装系统提示词            │
│ style.css  古风排版   │ ◄────────────────── │ （世界观/人设/面板约束/    │
│ app.js     游戏逻辑   │   叙述+选项+状态增量  │  输出格式规范）           │
│  - 状态面板           │                    │ 调用 DeepSeek v4 Flash    │
│  - 打字动画           │   POST /api/summarize│ 解析【选项】【状态】JSON   │
│  - 存档/读档/导入导出  │ ──────────────────► │ 历史浓缩为"大事记"摘要     │
└──────────────────────┘                    └─────────────────────────┘
```

**每轮协议**：前端发送 `[最近20轮对话 + 状态面板 + 大事记摘要]` → 后端拼装提示词调 DeepSeek → 返回 `叙述正文 + 【选项】 + 【状态】JSON` → 前端渲染、钳制状态、更新面板。
